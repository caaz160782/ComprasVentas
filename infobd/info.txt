se creara un contenedor en docker de una bd en postgresSQl

*** se puede alimentar desde un file SQl pero preferiblemente mejor ocupar migrations
nombre de la bd appdb
ejecutar 
1.docker compose down -v
2.docker compose up -d --build

migraciones 

instalar libreria 
dotnet tool install --global dotnet-ef
dotnet add package Microsoft.EntityFrameworkCore.Design
dotnet add package Npgsql.EntityFrameworkCore.PostgreSQL

dotnet ef migrations add initialBD
dotnet ef database update
